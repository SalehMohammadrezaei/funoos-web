Funoos on the web

Funoos is a free, open-source desktop laboratory for two-dimensional fluid motion and pattern formation, created by Saleh Mohammadrezaei (University of Manchester). This site is the same laboratory with the running already done: every case here was computed with the desktop app, version 1.3.2, at the app's High resolution and 1.8× the reference duration, then rendered with the app's own views, measurements, diagnostic plots and explanations.

The pages offer fixed choices. If you want a value that is not listed, a different geometry, your own text in the wind tunnel, a longer run or a colour palette change, install Funoos: it runs on macOS, Windows and Linux and needs no account.

What is here

  • 28 experiments, 216 pre-run cases. All 51 presets of the app are included unchanged; the extra cases sweep the parameters each experiment is about, at values that pass the app's own validity checks with no warnings.
  • Every clip is the app's rendering (H.264, longest side 960 px, 24 frames per second, 647 clips in all).
  • Measurements and plots come from the app's diagnostics module; the explanation layers, equations and references are the app's own text.
  • Each case records the solver's quality assessment. A case reads "qualitatively" when the solver itself reported a reason, for example a speed limiter that fired or a pore Reynolds number above one.

How the cases were produced

A batch script ran every case through the app's engine on one workstation (about 209.3 processor-hours of wall time across the jobs), checked that the solver finished, that all fields and frames are finite, that the measurements are finite and that each clip changes over time, and recorded the solver's quality notes. The scripts are in the site repository.
